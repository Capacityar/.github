# Capacityar — Organización

Repositorio central de la organización **Capacityar**: perfil público, documentación y GitHub Pages.

Capacityar es un Sistema de Tutoría Inteligente (ITS) que capacita a jóvenes de barrios vulnerables de Argentina para insertarse en el sector IT, articulado sobre el modelo pedagógico de las **5 P** (Pasión, Play, Práctica, Paciencia, Perseverancia) con esquema **Human-in-the-Loop (HITL)**.

## Repositorios

| Repo | Descripción |
|------|-------------|
| [backend](https://github.com/Capacityar/backend) | API FastAPI + PostgreSQL + IA (Groq/Gemini) |
| [frontend](https://github.com/Capacityar/frontend) | React 19 + Vite + TypeScript + Tailwind |
| `.github` | Perfil de org, documentación y GitHub Pages |
